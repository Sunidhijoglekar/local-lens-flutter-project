# 📍 Local Lens

Local Lens is a Flutter-based application designed to help users discover and explore local places and services in an easy and convenient way.

## ✨ Features

* 🔍 Discover local places and services
* 📍 Location-based exploration
* 🗺️ View places and locations
* 👤 User-friendly interface
* ⭐ Explore local businesses and services
* 💳 Stripe payment integration
* 🔥 Firebase backend integration

## 🛠️ Technologies Used

* **Flutter & Dart** — Mobile application development
* **Firebase** — Backend services and data management
* **Stripe** — Payment processing
* **Node.js** — Backend/payment services

## 🚀 Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Firebase account

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Sunidhijoglekar/local-lens-flutter-project.git
```

2. Open the project:

```bash
cd local-lens-flutter-project
```

3. Install Flutter dependencies:

```bash
flutter pub get
```

4. Configure your Firebase and environment variables.

5. Run the application:

```bash
flutter run
```

## 🔐 Environment Variables

For security reasons, API keys and secret credentials are **not included in this repository**.

Create the required `.env` file locally and add your own credentials.

**Never commit API keys, passwords, or secret keys to GitHub.**
